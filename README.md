
# YOLOv8目标检测系统
这是一个基于YOLOv8模型的目标检测系统，包含模型推理、界面展示、报警功能等模块。系统结构清晰，易于扩展和维护
## 目录结构
- `config/`：存放系统配置文件，如模型路径、报警阈值
- `models/`：存放训练好的模型文件（.pt格式）
- `test_images/`：存放测试用的图片
- `utils/`：工具模块，包含日志记录、报警处理、全局变量等功能
- `yoloshow/`：界面模块，包含主窗口和对比模式窗口的实现
- `yolo.py`：模型推理核心模块，负责加载模型并进行目标检测
- `main.py`：程序入口，负责初始化系统并启动界面
- `requirements.txt`：列出系统依赖的Python库
## 功能介绍
- **模型推理**：使用YOLOv8模型进行目标检测，支持加载训练好的模型文件
- **界面展示**：提供主窗口显示检测结果，并支持切换到对比模式窗口进行结果对比
- **报警功能**：当检测到特定目标时，触发报警功能，提供视觉和声音提示
- **日志记录**：系统运行过程中会记录日志，方便调试和问题排查
## 使用说明
1. 安装依赖：运行 `pip install -r requirements.txt` 安装所需的Python库
2. 准备模型：将训练好的YOLOv8模型文件（.pt格式）放入 `models/` 目录（github仓库中已包含一个示例模型文件 `yolov8l-best.pt`）
3. 准备测试图片：将测试用的图片放入 `test_images/` 目录
4. 运行程序：执行 `python main.py` 启动系统，界面将显示检测结果
5. 切换界面：在主窗口中点击按钮可以切换到对比模式窗口，进行结果对比
